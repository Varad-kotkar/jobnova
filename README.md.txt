# JobNova

## Vision

JobNova is an AI-powered career discovery platform focused on India and Remote tech jobs.

## Mission

Help students and professionals discover verified opportunities automatically.

## Core Features

- Automatic job discovery
- AI enrichment
- SEO job pages
- Telegram alerts
- Resume tools (future)
- Interview preparation (future)

## Tech Stack

Frontend:
- Next.js

Backend:
- FastAPI

Database:
- PostgreSQL (Supabase)

Automation:
- GitHub Actions

Hosting:
- DigitalOcean

AI:
- ChatGPT
- GitHub Copilot

## Architecture

Orchestrator → Collector → Validator → Deduplicator → Enrichment → SEO → Publisher
